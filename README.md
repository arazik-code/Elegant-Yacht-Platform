## 🌐 Deployment (Vercel)

This project is optimized for zero-config deployment on Vercel.

1.  **Push to GitHub**:
    ```bash
    git push origin main
    ```
2.  **Import in Vercel**: Connect your repository.
3.  **Environment Variables**: Add your keys (Cloudinary, Database, Clerk).
4.  **Deploy**: Vercel handles the build, CDN distribution, and edge functions automatically.

## 📦 Local Development

To run the platform locally for development or demo:

```bash
# 1. Install dependencies
npm install

# 2. Setup Database
npx prisma generate
npx prisma db push

# 3. Start Server
npm run dev
```

Visit `http://localhost:3000` to see the platform.
